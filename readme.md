# Rotate-Paper

This repository contains the sources for the paper
URL

## Running the measurements

### Prerequisites

- Nix package manager (recommended) - Provides Node.js and all dependencies automatically

### Setup

   ```bash
   git clone https://github.com/kubux/rotate-paper.git
   cd rotate-paper
   ```

### Install the dependencies

   ```bash
   nix develop
   ```

### Compile the paper

   ```bash
   make
   ```
   
   This will make all measurements on your local machine and create the paper with figures showing those measurements. Beware: this may take days.
